# AquaTrust AI — Definition of Done

A phase is DONE only when all applicable criteria below are satisfied.

## Implementation
- [ ] Scope implemented completely.
- [ ] No required item left as a placeholder.
- [ ] No unauthorized scope expansion.

## Contracts
- [ ] Data contracts preserved.
- [ ] API contracts preserved or formally updated.
- [ ] No undocumented breaking change.

## Quality
- [ ] Unit tests pass.
- [ ] Integration tests pass.
- [ ] Negative/error-path tests pass.
- [ ] Regression tests pass.

## Security
- [ ] Authorization enforced where applicable.
- [ ] No secrets committed.
- [ ] No fabricated evidence.
- [ ] Input validation present.

## Data
- [ ] Database migrations tested where applicable.
- [ ] Existing data is not corrupted.
- [ ] Provenance/audit behavior is correct.

## Integration
- [ ] Previous phases still function.
- [ ] New functionality is reachable through the intended interfaces.
- [ ] Frontend/API integration is correct where applicable.

## Documentation
- [ ] Files created/modified are listed.
- [ ] Schema/API changes documented.
- [ ] Known limitations documented.
- [ ] Deferred work documented.
- [ ] Completion report generated.

## Final gate
- [ ] Human review can reproduce the result.
- [ ] Phase is explicitly marked FROZEN.
