## 2. Ingestion & Integrity Verification

To verify that all raw datasets are present and match their authoritative SHA-256 checksums byte-for-byte:

```bash
# Run integrity verification script
python datasets/scripts/verify_dataset_integrity.py

# Run ingestion verification utility
python datasets/scripts/ingest_datasets.py
```

## 3. Authoritative Data Principles

1. **Raw Data Immutability:** Files in `raw/` are immutable and read-only.
2. **Distinctness:** Datasets 1–4 are never row-wise merged or concatenated to fabricate complete events.
3. **No Parameter Fabrication:** If a parameter is unmonitored in a source, it remains `null` in canonical representations.
4. **Distinguishable Origins:** All records carry explicit `data_origin: observed` vs `data_origin: simulated`.
5. **Separation of Statuses:** `quality_status` (validation), `anomaly_status` (AI), and `compliance_status` (QA) remain strictly separate.
