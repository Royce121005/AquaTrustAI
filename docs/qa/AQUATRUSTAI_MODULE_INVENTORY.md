## 1. Executive Overview

This inventory captures **every module, service, screen, endpoint, model, and engine** discovered in the AquaTrustAI repository. In accordance with the Master QA mandate, no module has been skipped, and no feature has been assumed to exist based solely on documentation.

Every entry has been cross-referenced with actual source files, registered FastAPI routes in `backend/app/main.py` and `backend/app/api/router.py`, React Router declarations in `frontend/src/App.tsx`, SQLAlchemy ORM classes in `backend/app/models/`, ML models in `ml/models/`, and Hyperledger Fabric contracts in `dlt/`.
